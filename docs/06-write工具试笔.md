# write 工具试笔

这篇是 `write` 工具的第一次调用产物，不是设计文档。

## 为什么写在这

`docs/` 已经有 `00`–`05` 与 `实现现状.md`。挑这里是为了**不污染 `src/` 与 `tests/`**——
那两处是代码与测试，一个试笔文件混进去只会让 `git status` 变脏。

⚠️ 编号 `06` 是**随手挑的**，不代表它继承了那条系列的体例。真要为 `head/` 之外的第六篇
排个位，得先看 `docs/README.md` 怎么说。

## 记一件事

`write` 是**整份覆盖**：文件不存在就新建，已存在就**整个**盖掉。
⇒ 改已存在文件的一处，用 `update`（它只动点到的那一段），**别用 `write`**——
整份写要求把全文都写对，而**漏一行是看不出来的**。

这与 `01` §8.0.2 那条同形：**能定点做的，就不要全量做**。
